Mirage Bay is an original offline third-person 3D coastal arcade adventure. Explore Palisade Avenue, Palm Row, and Harborlight District in a saturated sunset city, complete the Sol Mercer story mission, evade fictional pursuit units, and shake off wanted heat with an abstract nonlethal EMP.

## Controls

**WASD** walk or drive · **Mouse** aim camera · **E** enter or leave a vehicle · **Q** fire EMP · **Shift** sprint or boost · **Escape** pause · **M** mute.

## Run it

```sh
node serve.ts
```

Open `http://localhost:8080`. The game is fully local and has no build step or runtime network dependency.

Mirage Bay uses vendored **three.js 0.160.1**; see `game/vendor/THREE-LICENSE.txt` for the MIT license and attribution.
